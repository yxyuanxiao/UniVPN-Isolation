UniVPN Apple Container 隔离方案
================================

用途
----
把 Linux ARM64 版 UniVPN 封装在 Apple Container 中。UniVPN 的默认路由、DNS、
虚拟网卡和自动重连都只发生在容器内，不再接管 macOS。

日常使用
--------
1. 双击 start.command，输入一次 macOS 管理员密码。
2. 浏览器会打开隔离桌面。需要时在里面登录 UniVPN。
   自动登录会保留，但服务器证书未受信任，每次启动后仍需人工确认 Continue。
3. 访问 10.10.128.xxx。代理服务端硬性只允许 10.10.128.0/24。
4. 使用结束后双击 stop.command。

容器未启动时
------------
10.10.128.0/24 不会被发送到 UniVPN；系统恢复原有的 10.0.0.0/8 直连绕过规则。
因此电脑直接接入内网时不需要启动容器。

端口
----
127.0.0.1:16080  noVNC 隔离桌面
127.0.0.1:15902  SOCKS5，仅允许 TCP 目标 10.10.128.0/24

安全说明
--------
两个端口都只绑定 macOS 回环地址。UniVPN 配置保存在 Apple Container 的命名卷
univpn-config 中，不在镜像、脚本或 README 中保存账号密码。

分流范围
--------
PAC 分流适用于浏览器和遵循 macOS 系统代理的应用。命令行工具可按需显式指定
SOCKS5 127.0.0.1:15902；Dante 仍会拒绝 10.10.128.0/24 以外的目标。

其他
----
status.command 可查看当前状态。macOS 原 UniVPN 的自动登录设置未被修改。
